     6→## PRODUCT CONTEXT
     7→Reliastra is External Dependency Intelligence. It monitors third-party APIs (Stripe, Auth0, Cloudflare, OpenAI, etc.) from independent geographic locations. When a vendor fails, it correlates that failure with the customer's own service degradation and generates timestamped SLA evidence reports (PDF) that customers use to claim credits from vendors or prove fault to clients.
     8→
     9→Target ICPs:
    10→1. SaaS Founders (12-50 employees, revenue depends on uptime)
    11→2. Digital Agencies (managing 20-200 client sites, reputation on the line)
    12→3. DevOps/Platform Engineers (using Datadog/Grafana, need external validation)
    13→4. Engineering Managers (need vendor accountability, procurement evidence)

   384→### 1. Hero Canvas Chart
   385→- Self-contained React component using Canvas API.
   386→- 6 vendor rows. Each row updates independently.
   387→- Latency values: generated with realistic base + random jitter.
   388→- Status changes: probabilistic (98% up, 1.5% degraded, 0.5% down).
   389→- When status changes, the row background flashes (success/amber/danger at 10% opacity for 300ms).
   390→- Sparklines: 40px tall, 100px wide, drawn as connected lines with Canvas path.
   391→- Updates every 2000ms using setInterval (cleaned up on unmount).
   392→- On mobile: show 3 vendors instead of 6.
   393→
   394→### 2. Scroll Reveal Animations
   395→- Use Framer Motion's `whileInView` with `viewport={{ once: true, margin: "-100px" }}`.
   396→- Default: opacity 0 → 1, y: 30 → 0, duration 0.6s, ease [0.25, 0.1, 0.25, 1].
   397→- Stagger children: staggerChildren 0.1s.
   398→- Sections fade in as user scrolls. No section appears without animation.
   399→
   400→### 3. Counter Animation
   401→- The founding spots counter animates with Framer Motion `useMotionValue` + `useTransform`.
   402→- Numbers count up/down with spring physics when data updates.
   403→- Duration: 1.2s, bounce: 0.
   404→
   405→### 4. Hover States
   406→- Cards: translateY(-4px), shadow-elevated, border-accent/30. Transition: all 300ms cubic-bezier(0.4, 0, 0.2, 1).
   407→- Buttons: scale(1.02) on hover. Active: scale(0.98).
   408→- Links: color transition 150ms.
   409→
   410→### 5. Navigation Scroll Effect
   411→- useEffect hook: listen to scroll. If scrollY > 20, add `scrolled` class to nav.

   417→- SVG arrow: stroke-dasharray set to path length, stroke-dashoffset animates from full length to 0 over 1s.
   418→- Triggered when section enters viewport (Intersection Observer).
