## PRODUCT CONTEXT
Reliastra is External Dependency Intelligence. It monitors third-party APIs (Stripe, Auth0, Cloudflare, OpenAI, etc.) from independent geographic locations. When a vendor fails, it correlates that failure with the customer's own service degradation and generates timestamped SLA evidence reports (PDF) that customers use to claim credits from vendors or prove fault to clients.

Target ICPs:
1. SaaS Founders (12-50 employees, revenue depends on uptime)
2. Digital Agencies (managing 20-200 client sites, reputation on the line)
3. DevOps/Platform Engineers (using Datadog/Grafana, need external validation)
4. Engineering Managers (need vendor accountability, procurement evidence)

## ABSOLUTE RULES (VIOLATE = INSTANT REJECTION)

7. MOBILE-FIRST RESPONSIVE. Every section must be thumb-friendly. Touch targets min 44px.

## DYNAMIC ELEMENTS SPECIFICATIONS

### 1. Hero Canvas Chart
- Self-contained React component using Canvas API.
- 6 vendor rows. Each row updates independently.
- Latency values: generated with realistic base + random jitter.
- Status changes: probabilistic (98% up, 1.5% degraded, 0.5% down).
- When status changes, the row background flashes (success/amber/danger at 10% opacity for 300ms).
- Sparklines: 40px tall, 100px wide, drawn as connected lines with Canvas path.
- Updates every 2000ms using setInterval (cleaned up on unmount).
- On mobile: show 3 vendors instead of 6.

### 2. Scroll Reveal Animations
- Use Framer Motion's `whileInView` with `viewport={{ once: true, margin: "-100px" }}`.
- Default: opacity 0 → 1, y: 30 → 0, duration 0.6s, ease [0.25, 0.1, 0.25, 1].
- Stagger children: staggerChildren 0.1s.
- Sections fade in as user scrolls. No section appears without animation.

### 3. Counter Animation
- The founding spots counter animates with Framer Motion `useMotionValue` + `useTransform`.
- Numbers count up/down with spring physics when data updates.
- Duration: 1.2s, bounce: 0.

### 4. Hover States
- Cards: translateY(-4px), shadow-elevated, border-accent/30. Transition: all 300ms cubic-bezier(0.4, 0, 0.2, 1).
- Buttons: scale(1.02) on hover. Active: scale(0.98).
- Links: color transition 150ms.

### 5. Navigation Scroll Effect
- useEffect hook: listen to scroll. If scrollY > 20, add `scrolled` class to nav.
- `scrolled` state: add shadow-md, border-border-default.

### 6. Live Correlation Timeline Animation
- CSS + SVG animation.
- Red blocks slide in from left (transform: translateX(-20px) → 0, opacity 0 → 1, 0.5s).
- SVG arrow: stroke-dasharray set to path length, stroke-dashoffset animates from full length to 0 over 1s.
- Triggered when section enters viewport (Intersection Observer).

### 7. Evidence Report Scan Line
- CSS animation: linear gradient moves vertically down the report mockup.
- `background: linear-gradient(to bottom, transparent, rgba(8,145,178,0.05), transparent); background-size: 100% 50%; animation: scan 5s linear infinite;`
- Creates "generating" effect.

## COPYWRITING PRINCIPLES

1. Headlines are outcomes, not features. "Know it's your vendor's fault" not "Vendor monitoring tool."
2. Every sentence answers "so what?" for the reader.
3. No jargon without explanation. "SLA" is fine, but explain the value.
4. Active voice. "We generate evidence" not "Evidence is generated."
5. Specific over vague. "23 minutes" not "extended downtime."
6. Confident, never desperate. No exclamation points. No "amazing!!!" No "revolutionary."
7. The word "Prove" is a power word. Use it intentionally.
